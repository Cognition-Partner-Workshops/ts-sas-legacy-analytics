# W0-R reference build — ambiguity record

Rule (DEC-004 / R-0 option b): where the SAS source and the tolerance record
(`.migration/03_recon_tolerances.md` v1) or the analysis (`docs/migration/ts-sas-legacy-analytics_P1_banking_core_analysis.md` §6)
disagree, the reference implements the **literal Base SAS reading** and records both readings here.
Where the non-literal reading is what a migrating child is likely to build, the alternate is
materialised under `reference/alternates/` so the recon owner can switch after a decision is logged
in `.migration/06_decisions.md`. Nothing here changes a tolerance.
